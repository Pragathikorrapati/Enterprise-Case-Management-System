# Enterprise Case Management System

A full-stack enterprise portfolio application demonstrating modern **.NET 8**, **ASP.NET Core Web API**, **Angular 18**, **TypeScript**, and accessible responsive UI development.

> This is an original portfolio project created for technical demonstration purposes. It does not contain proprietary code, confidential information, or data from any employer or client.

## Technology Stack

### Backend
- C# / .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- RESTful APIs
- Swagger / OpenAPI
- SQL Server

### Frontend
- Angular 18
- TypeScript
- HTML5
- CSS3
- Responsive Web Design

### Accessibility & UI/UX
- WCAG 2.1 AA principles
- Section 508 accessibility practices
- Semantic HTML
- Keyboard-friendly navigation
- Accessible form labels
- Visible focus indicators
- Responsive layouts

## Application Features

- Enterprise case management dashboard
- Case search and filtering
- Case status management
- New case creation
- REST API integration
- Input validation
- Responsive user interface
- Accessible form controls
- Demo data for portfolio demonstration

## Architecture

The application demonstrates separation between presentation, API, business, and data-access concerns using modern enterprise development practices.

The Angular frontend communicates with an ASP.NET Core REST API, while Entity Framework Core provides the application data-access layer.

## Purpose

This repository serves as a professional code sample demonstrating full-stack .NET development, REST API design, Angular UI development, responsive design, accessibility practices, and enterprise application architecture.
